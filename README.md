# 🤖 Antigravity Telegram Suite

**Работает как с [Antigravity Standalone App](https://antigravity.google/), так и с [Antigravity IDE](https://antigravity.google/).**

🌍 Языки / Languages: [Русский](README.md) | [English](README.en.md) | [中文](README.zh.md) | [한국어](README.ko.md) | [Türkçe](README.tr.md) | [Deutsch](README.de.md) | [Español](README.es.md) | [Français](README.fr.md)

Удалённое управление ИИ-агентом Google Antigravity через Telegram.
Отправляйте сообщения, переключайте модели ИИ, управляйте проектами, делайте скриншоты и запускайте мультиагентные сценарии прямо со своего смартфона.

| Функция | Описание |
|---|---|
| 💬 **Фоновый чат (Headless)** | Прямая отправка сообщений ИИ-агенту через Telegram |
| 📎 **Загрузка файлов и картинок** | Пересылка изображений и файлов агенту с текстовыми подписями |
| 📸 **Скриншоты IDE** | Удалённое создание и получение скриншотов рабочего окна |
| 🤖 **Выбор моделей и уровня мышления** | Смена моделей ИИ и уровня рассуждений (Low / Medium / High) через удобные двухэтапные inline-кнопки |
| 📂 **Проводник файлов** | Просмотр, навигация и скачивание файлов проектов |
| 🔄 **Управление проектами** | Переключение между рабочими пространствами без клавиатуры |
| 🪟 **Поддержка нескольких окон** | Направление команд в конкретное окно IDE при одновременной работе нескольких |
| 👥 **Многопользовательский режим** | Совместный доступ для команды через список Chat ID, разделённых запятыми |
| 💬 **Интерактивные треды чатов** | Кнопочный интерфейс со списком недавних чатов, папками проектов, быстрым поиском (`/agents <запрос>`) и мгновенным переключением по UUID |
| ⚡ **Авто-подтверждение (Auto-Accept)** | Автоматическое нажатие кнопок Run, Accept, Allow, Continue через DOM MutationObserver |
| 🚀 **Турбо-режим (Turbo Mode)** | Мультиагентный конвейер: Claude планирует → Gemini кодит → Claude ревьюит → Gemini исправляет |
| 🎯 **Режим цели (Goal Mode)** | Автономные долговременные задачи — агент работает непрерывно до полного завершения |
| 📋 **Режим плана (Plan Mode)** | Составление подробного плана реализации перед написанием кода |
| 🔔 **Проактивные уведомления** | TaskWatcher отслеживает спонтанные сообщения агента (таймеры, сабагенты) и пересылает в Telegram |
| 🤔 **Реакции на сообщения** | Реакция 🤔 во время обработки, снимается по завершении |
| 🔄 **Самообновление** | Проверка наличия обновлений и обновление одной командой |
| 🌐 **Мультиязычность** | Полная локализация интерфейса: русский, английский, китайский, корейский, турецкий, немецкий, испанский, французский |
| ⌨️ **Индикатор набора** | Отображение статуса "печатает..." в Telegram, пока агент занят работой |
| 🖥️ **Кроссплатформенность** | Работает на Linux, macOS (Intel и Apple Silicon) и Windows |
| 🔀 **Поддержка двух приложений** | Бесшовное переключение между Antigravity IDE и Standalone Agent App |
| 🔐 **Переключение Google-аккаунтов** | Авторизация и переключение между аккаунтами Google с прямой записью токенов в БД IDE или системную связку ключей |
| 📡 **Публикация в Telegraph** | Чеклисты задач, планы и walkthrough-инструкции публикуются со скрытыми ссылками (или отправляются приватно в чат) с управлением и очисткой |

## 🚀 Быстрый старт

### Требования

- **Поддержка двух сред (IDE и Standalone):** Мгновенное переключение между Classic Monaco IDE и Standalone Agent с помощью команды `/app`. Изолированные драйверы гарантируют отсутствие конфликтов и чистое завершение фоновых процессов.
- [Node.js](https://nodejs.org/) >= 18
- Установленные [Antigravity IDE](https://antigravity.google/) и/или [Antigravity Standalone App](https://antigravity.google/)
- Токен Telegram-бота (получите у [@BotFather](https://t.me/BotFather))

### 1. Клонирование и установка

```bash
git clone https://github.com/coldmayg/antigravity-telegram-suite.git
cd antigravity-telegram-suite
npm install
```

### 2. Настройка

```bash
cp .env.example .env
```

Отредактируйте `.env`:

```env
# Telegram
BOT_TOKEN=ваш_токен_бота
ALLOWED_CHAT_ID=ваш_chat_id,chat_id_коллеги_опционально

# CDP Порты отладки (должны совпадать с параметром --remote-debugging-port при запуске)
AGENT_CDP_PORT=9333    # Порт для Standalone Antigravity App
IDE_CDP_PORT=9334      # Порт для Antigravity IDE

# Модель ИИ по умолчанию
DEFAULT_MODEL=Gemini 3.5 Flash (Medium)

# Язык по умолчанию: ru | en | zh | ko | tr | de | es | fr
LANGUAGE=ru

# Основное приложение: 'agent' (Standalone) или 'ide' (IDE)
ANTIGRAVITY_PREFERRED_APP=ide

# Авто-подтверждение по умолчанию
AUTOACCEPT_DEFAULT=true

# Публикация артефактов в Telegraph (по умолчанию: true)
ENABLE_TELEGRAPH=true

# Фильтр отображаемых моделей в команде /getinfo (через запятую)
QUOTA_DISPLAY_MODELS=Claude Opus 4.6,Claude Sonnet 4.6,Gemini 3.5 Flash (High),Gemini 3.5 Flash (Low),Gemini 3.5 Flash (Medium),Gemini 3.1 Pro (High),Gemini 3.1 Pro (Low)
```

> 💡 Отправьте `/start` вашему боту в Telegram, чтобы узнать ваш Chat ID.

### 3. Запуск приложения с поддержкой CDP

Бот управляет Antigravity через протокол Chrome DevTools Protocol (CDP). Приложение необходимо запускать с указанием отладочного порта.

#### 🚀 Запуск бота и сторожевого процесса (Watchdog)

Для непрерывной работы в фоновом режиме с автоматическим перезапуском при сбоях:

```bash
npm run watchdog
```

Или прямой запуск бота:

```bash
npm start
```

#### Ручной запуск Antigravity

**При одновременном запуске обоих приложений используйте разные порты:**

```bash
# --- Standalone Antigravity App ---
# Linux
antigravity --remote-debugging-port=9333

# macOS
open -a Antigravity --args --remote-debugging-port=9333

# Windows
Antigravity.exe --remote-debugging-port=9333
```

```bash
# --- Antigravity IDE ---
# Linux
antigravity-ide --remote-debugging-port=9334

# macOS
open -a "Antigravity IDE" --args --remote-debugging-port=9334

# Windows
"Antigravity IDE.exe" --remote-debugging-port=9334
```

> ⚠️ Номера портов должны строго совпадать с переменными `AGENT_CDP_PORT` и `IDE_CDP_PORT` в вашем `.env`.

### 4. Запуск в режиме 24/7 (PM2)

```bash
npm install -g pm2
pm2 start src/index.js --name antigravity-bot
pm2 save
pm2 startup
```

### Автоматическая установка

```bash
# Linux и macOS
bash scripts/install.sh

# Windows (PowerShell)
powershell -ExecutionPolicy Bypass -File scripts\install.ps1
```

## 🚀 Турбо-режим (Мультиагентная оркестрация)

Турбо-режим реализует алгоритм **Совета Агентов (Agents Council)**, автоматически координируя несколько моделей:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        КОНВЕЙЕР ТУРБО-РЕЖИМА                           │
│                                                                        │
│  Этап 1: ПЛАНИРОВАНИЕ  Claude Opus → Составляет детальный план         │
│  Этап 2: РАЗРАБОТКА    Gemini Pro  → Пишет исходный код                │
│  Этап 3: РЕВЬЮ         Claude Opus → Проверяет безопасность и логику   │
│  Этап 4: ИСПРАВЛЕНИЕ   Gemini Pro  → Устраняет найденные замечания     │
│  Этап 5: СВОДКА        Gemini Pro  → Готовит итоговый отчёт            │
└────────────────────────────────────────────────────────────────────────┘
```

**Как использовать:**
1. Включите турбо-режим: `/turbo` → Нажмите "Включить"
2. Отправьте ваш запрос обычным текстом
3. Бот автоматически переключит модели и последовательно пройдёт все этапы
4. Вы будете получать обновления по каждому этапу в реальном времени и итоговую сводку

## 🎯 Режим цели vs 🚀 Турбо-режим

| Параметр | Режим цели (`/goal`) | Турбо-режим (`/turbo`) |
|---|---|---|
| **Принцип работы** | Агент работает автономно в одной сессии до завершения | Внешняя оркестрация конвейера нескольких моделей |
| **Используемые модели** | Текущая выбранная модель | Claude (план/ревью) + Gemini (код/фикс) — автопереключение |
| **Главный плюс** | Простота, надёжность, нативная функция IDE | Взаимный контроль: разные архитектуры перепроверяют друг друга |
| **Расход токенов** | Один контекст (экономно) | Несколько раундов (повышенный расход) |
| **Отслеживание** | Реакция 🤔 → финальный результат | Закреплённое сообщение с пошаговым статусом в реальном времени |
| **Лучше всего для** | Длительных задач с одной моделью | Комплексных задач, требующих строгого ревью кода |
